# Неблокирующий экран выбора персонажа

31 октября 2026. По прямому требованию пользователя переход не блокируется ожиданием загрузок. Нажатие «Выживание» сразу открывает экран; кнопка не отключается, загрузочный диалог и ожидание всех портретов отсутствуют. Переключение персонажа также синхронно меняет выбранного героя и его описание.

Экран создаётся скрытым в главном меню. Выбранный портрет, аватары и активки начинают готовиться заранее; остальные 15 крупных портретов подготавливаются с ограничением в три параллельных запроса. Все вызовы используют общий кеш декодированных изображений. Для нечётких сетевых ошибок успешные файлы сохраняются, повтор загружает неудачные. При dispose очередь больше не начинает новые запросы.

В начальный JS включены лёгкие WebP-превью: все портреты 96×144, аватары тайлами64×96 и активки тайлами48×48. Всего71372байта изображений (около72КБgzip модуля). Поэтому даже если все внешние изображения задержаны/недоступны, интерфейс сразу имеет изображения, а не пустые места. Полные версии подменяют превью после готовности; при готовом кеше промежуточная миниатюра не показывается. На медленной сети различие резкости будет видно, это не обещание мгновенного скачивания полного качества.

Цена: начальный JS gzip вырос примерно с102 до176КБ. Этот небольшой обязательный объём заменяет отдельные запросы к превью при кликах. Полные файлы и их качество сохранены. Музыка меню имеет preload none и начинает загрузку после подготовки основных картинок, чтобы не конкурировать с ними с первого кадра.

Проверка Edge: при полностью удерживаемых внешних PNG/WebP переход остаётся доступен, все15героев переключаются сразу и имеют встроенные портреты, аватары и активки. После снятия задержки полное разрешение появляется, повторное открытие около20мс, бой запускается, ошибокJS нет. Полное время первого автоматизированного click было639мс, включая ожидание стабильности анимированной кнопки в Playwright; это не время ожидания сети. Артефакты `output/fast4g/nonblocking-selection.cjs`, `instant-preview.png`, `nonblocking-results.json`.

344 теста, TypeScript и production build проходят. Генератор: `npm run assets:selection-previews`, проверка: `npm run assets:selection-previews:check`. Встроенный бюджет80КБ контролируется генератором, оригиналы проверены SHA256 и сохранены.
