# Оптимизация портретов — 28 октября 2026

> Обновление 29 октября, [BUG-006](bugs.md): описанные ниже lossless-версии заменены производными WebP с качеством 88 для портретов (до 768×1152) и 85 для миниатюр (до 192×288). Суммарный объём сокращён с 31,66 до 2,65 МиБ. Пропорции и исходные PNG сохранены; побитовое совпадение пикселей больше не является требованием. Ниже оставлен исторический результат первого этапа.

Для 15 портретов подготовлены отдельные игровые версии в `src/assets/portraits-runtime/`. PNG-оригиналы в `src/assets/characters/` сохранены и не используются как миниатюры.

## Две версии для разных задач

- `full/`: WebP со сжатием без потерь, исходное разрешение 1024×1536. Генератор декодирует результат и сравнивает каждый RGBA-пиксель с исходником: требуется полное совпадение.
- `thumbnail/`: 512×768, пропорциональное уменьшение Lanczos3 и WebP без дополнительного сжатия с потерями. Прозрачные поля и композиция не обрезаются. Эти версии используются только в ленте персонажей.

Первый вариант миниатюр 320×480 был отклонён после увеличенного сравнения из-за смягчения мелких деталей. Выбран более консервативный размер 512×768. Крупный портрет всегда использует полную версию. CSS-позиционирование и размеры элементов не изменены.

При открытии подготовки загружаются миниатюры и один выбранный крупный портрет. Остальные крупные изображения запрашиваются при выборе героя. Последующим этапом [отложенной загрузки](lazy-art-loading.md) создание экрана перенесено на первое открытие «Выживания», поэтому главное меню больше не загружает портреты скрытого экрана.

## Воспроизводимость

```sh
npm run assets:portraits
npm run assets:portraits:check
```

Генератор `scripts/optimize-portraits.mjs` использует фиксированный список оригиналов, независимый от импортов в интерфейсе. `manifest.json` содержит SHA256 исходников и обеих версий, исходный RGBA-хеш, размеры, байты и настройки Sharp/libvips. Проверка повторяет генерацию без записи и сверяет результат с файлами и манифестом. Зависимости зафиксированы в lockfile.

## Проверка качества

Все 182 теста и итоговая production-сборка прошли. Повторная генерация `--check` прошла для окончательных миниатюр 512×768. Хеши 15 оригиналов не изменились; в сборке находятся все 30 новых файлов и ни одного из этих 15 исходных PNG.

Объём 15 оригиналов — 37,21 МиБ; полных WebP — 24,85 МиБ; миниатюр — 6,81 МиБ; вместе — 31,66 МиБ (−14,9%). При открытии экрана с Наёмником запрашиваются портретные файлы суммарно 8,56 МиБ вместо 37,21 МиБ. Это сумма размеров файлов, а не замер времени загрузки; сетевой сценарий подтвердил только один запрос крупного портрета до переключения. Остальные полные версии загружаются по мере выбора. Размер всей папки `dist/assets` после этапа — 88,35 МиБ.

Сравнения исходников с миниатюрами, скриншоты интерфейса и сценарий браузерной проверки сохранены в `output/playwright/portraits/`. Проверяется выбор всех 15 героев при DPR 1 и 3, разрешение крупных портретов и отсутствие загрузки невыбранных крупных изображений до первого переключения.

Итоговый браузерный прогон при DPR 1 и 3 прошёл. Сравнения всех 15 миниатюр в обычном и увеличенном размере осмотрены; заметного ухудшения при текущем размере карточек не обнаружено.

Сжатие полноразмерных портретов уменьшает файлы, но не объём их декодированных пикселей. Миниатюры сокращают пиксельный объём ленты. Это не замер FPS и не обещание ускорения боя; боевые модели, оружие и эффекты здесь не менялись.
