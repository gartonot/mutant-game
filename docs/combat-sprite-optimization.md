# Оптимизация боевых спрайтов

Выполнено 28 октября 2026 года для 15 персонажей и 3 типов врагов. Игра использует отдельные PNG-копии из `src/assets/combat-runtime/characters/` и `src/assets/combat-runtime/enemies/`. Исходники в `src/assets/characters/` (включая combat-v3/v4) и `src/assets/enemies/v1/` сохранены без изменений.

## Сохранение качества

Разрешение, холст, прозрачные поля и все RGBA-пиксели сохранены. Применено только сжатие PNG без палитры: compressionLevel 9, adaptiveFiltering true. Координаты тела, отдельных голов, ладоней и дула, порядок слоёв, повороты и отдача не менялись. Маски огня и льда также работают по прежней схеме.

WebP lossless был проверен, но не выбран: при точном совпадении декодированных RGBA браузер округлял полупрозрачные пиксели иначе. Итоговый PNG обеспечивает также точное совпадение проверенной браузерной отрисовки.

## Размеры

| Набор | Исходники | Игровые копии |
| --- | ---: | ---: |
| 15 персонажей | 21,25 МиБ | 19,92 МиБ |
| 3 врага | 2,83 МиБ | 2,67 МиБ |
| Все активные спрайты | 24,08 МиБ | 22,59 МиБ |

Сжатие активных файлов экономит 1,49 МиБ (6,2%). Кроме того, прежний glob включал в сборку шесть старых combat-v3 PNG, уже заменённых версиями combat-v4: ещё 11,02 МиБ. Новый glob ссылается только на runtime-копии активных персонажей; старые версии остаются на диске.

Вся папка `dist/assets`: **72,73 → 60,21 МиБ**, экономия **12,51 МиБ (17,2%)**. Это размер ресурсов сборки, а не замер трафика первого открытия. Распакованная память изображений и стоимость первого создания масок этим этапом не уменьшены; прирост FPS не измерялся.

## Повторный экспорт и проверки

- `npm run assets:combat` — пересоздать игровые PNG и манифест.
- `npm run assets:combat:check` — проверить воспроизводимость без записи.
- `manifest.json` содержит источники, размеры, вес, SHA-256 файлов и RGBA, хеши layout, настройки и версии инструментов. Экспорт проверяет полное равенство RGBA и неизменность исходников.
- Генерация и проверка прошли. Все 18 исходников сохранили SHA-256; все 18 копий присутствуют в сборке. Ни исходники, ни шесть устаревших v3 PNG в неё не включены (проверено по хешам).
- `npm test`: 182/182; `npm run build` прошёл.
- Edge: подтверждена загрузка всех 15 персонажей; 285 сочетаний с оружием при четырёх парах поворот/отдача (0°/0, 90°/6, 180°/3, 270°/6). SHA-256 RGBA всех 1140 Canvas совпали с исходной отрисовкой; ошибок опоры рук нет.
- Дополнительный Canvas с тремя типами врагов в трёх размерах и трёх состояниях (обычное, лёд, огонь) также совпал пиксельно. Снимок визуально проверен.

Локальные артефакты проверки: `output/playwright/combat/`. Скрипт `check.js` сохраняет исходные хеши в localStorage изолированной QA-сессии и при следующем запуске сравнивает с ними отрисовку; для нового сравнения нужно сначала снять новый эталон на исходных ресурсах.
