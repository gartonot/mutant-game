# Облегчённые игровые иконки

Первый этап оптимизации графики выполнен 27 октября 2026 года. Подключены 29 отдельных PNG-копий: 5 иконок патронов, 7 серебряных и 7 золотых бонусов, 10 улучшений.

## Оригиналы и воспроизводимость

Исходники остаются в `src/assets/ammo/v1/`, `src/assets/bonuses/v1/`, `src/assets/bonuses/gold-v1/` и `src/assets/upgrades/`. Генератор только читает их; не обрезает прозрачные поля и не меняет композицию. Референсы улучшений не обрабатываются.

Игра использует отдельный каталог `src/assets/icons-runtime/`. В нём `manifest.json` фиксирует пути, размеры, байты и SHA256 исходников и результатов, версии Sharp/libvips и настройки обработки.

Команды:

```sh
npm run assets:icons
npm run assets:icons:check
```

Первая команда заново создаёт игровые копии из оригиналов. Вторая без записи проверяет исходные хеши, метаданные и точное совпадение результата повторной генерации. Для повторения использовать зависимости из lockfile (`npm ci`). Sharp — только инструмент разработки, в браузер не включается.

## Размер и качество

Все текущие исходники — 1254×1254. Игровые копии — 256×256, Lanczos3, PNG без палитры и без дополнительного сжатия с потерями. Сам ресайз меняет пиксели, поэтому это не побитовое сохранение исходного изображения. Пропорции и прозрачные поля сохранены.

Размер выбран с запасом для текущего интерфейса: максимальное отображение бонуса 72 CSS px, иконки улучшения около 66 px, патронов 38 px. 256 px достаточно для этих размеров при DPR до 3. Если интерфейс начнёт показывать иконки крупнее, размер экспорта следует пересмотреть.

Общий размер 29 файлов: **49,21 → 2,66 МиБ**, уменьшение на **94,6%**. Это экономия конкретного набора файлов, не замер ускорения первого открытия или FPS.

## Проверки

- 29 пар исходник/копия осмотрены в браузере при размере 72 px и увеличенном размере 216 px. Заметной потери качества в текущих размерах интерфейса не обнаружено.
- В Edge проверены экраны улучшений и снаряжения, выбор расходника и запуск боя при DPR 2 и 3. Все 29 копий успешно декодируются; экран улучшений использует 10 новых изображений 256×256.
- Скриншоты до/после и сравнительные таблицы: `output/playwright/icons/`. `compare.html` открывается через Vite; `browser-check.js` — сценарий для Playwright CLI.
- `npm run assets:icons:check`, все 182 теста и production-сборка прошли.
- Независимая проверка SHA256: все 29 оригиналов совпадают с манифестом; в `dist/assets` присутствуют 29 хешей игровых копий и ни одного хеша этих оригиналов. Текущий размер всей папки `dist/assets` — 93,91 МиБ.

Боевые модели, портреты, модели оружия, маски огня/льда и порядок предварительной загрузки не входят в этот этап.
