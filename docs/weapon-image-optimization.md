# Оптимизация изображений оружия

Выполнено 28 октября 2026 года. Все 19 моделей используют игровые копии из `src/assets/weapons-runtime/`. Исходные PNG в `src/assets/weapons/v2/` и исходный `layout.ts` сохранены без изменений, что проверено по SHA-256.

## Экспорт и отрисовка

Генератор `scripts/optimize-weapons.mjs` вырезает ровно ту область исходника, которую раньше выбирал Canvas по `layout.ts`. Дополнительной обрезки прозрачности нет. Затем уменьшает длинную сторону до 768 пикселей без увеличения небольших исходников, используя Lanczos3, и сохраняет WebP с кодированием без потерь. Уменьшенные изображения не являются пиксельно идентичными оригиналам: кодирование без потерь применяется после масштабирования.

`WeaponSprites.ts` рисует уже обрезанные изображения целиком. Размеры назначения, ось оружия, хват, положение дула и геометрия карточек по-прежнему вычисляются по оригинальному layout. Загрузка и резервная отрисовка сохранены.

Пересоздать копии: `npm run assets:weapons`. Проверить воспроизводимость без записи: `npm run assets:weapons:check`. Манифест содержит размеры, вес, хеши исходников и копий, хеш layout, настройки и версии инструментов.

## Результат и проверки

- Набор оружия: **18,68 → 3,05 МиБ**, уменьшение **83,7%**.
- Вся папка `dist/assets` после сборки: около **72,73 МиБ** против 88,35 МиБ после этапа портретов. Это размер сборки, а не трафик первого открытия и не измерение FPS.
- Все 19 игровых копий включены в сборку; оригинальные PNG оружия в неё не попали (проверено по хешам).
- `npm test`: 182/182; `npm run build` и проверка генератора прошли.
- Браузерная галерея: 285 сочетаний (15 персонажей × 19 моделей), четыре пары поворота/отдачи: 0°/0, 90°/6, 180°/3, 270°/6. Проверка опоры не нашла ошибок.
- Визуально проверены все 19 моделей рядом с исходниками на светлом и тёмном фоне, в обычном и увеличенном размере, а также галерея боевой отрисовки и экран снаряжения при DPR 3. Заметного ухудшения качества не обнаружено.

Локальные снимки проверки находятся в `output/playwright/weapons/`, включая `comparison.png`, `comparison-large-dark.png`, `gallery-after.png` и `equipment-dpr3.png`.
