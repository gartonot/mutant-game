# Убийца: боевая модель v2

Продолжение принятого пользователем рисованного стиля Наёмника. Узнаваемые черты портрета: короткие рыжие волосы, красное платье, открытые руки, кожаные ремни и перчатки. Более узкие плечи и лёгкий силуэт отличают её от Наёмника. Камера сверху, мягкие тени, фактура материалов, без толстой чёрной обводки.

Референсы: портрет `src/assets/characters/assassin.png` и [игровой пример из прошлого обсуждения](references/assassin-gameplay.png).

Создано встроенным imagegen. Исходный PNG с альфа-каналом: `src/assets/characters/assassin-combat-v2.png`, 1774 × 887. Корпус с руками расположен в области x=0…1259, отдельная голова — x=1260…1773. PNG сохранён без редактирования. Портрет меню остаётся отдельным изображением.

Рендер в `src/rendering/AssassinArt.ts`: тень, корпус с руками, выбранное оружие и голова. Фиксированная поза, направление вперёд +X и общие точки крепления/дульного среза из `WeaponArt.ts`. Бой и экран подготовки вызывают общий `drawCharacter`. До загрузки PNG или при ошибке доступна прежняя Canvas-модель; предпросмотр обновляется по окончании загрузки.

По замечанию пользователя голова уменьшена на 25% по ширине и высоте относительно первоначального рендера, с сохранением точки крепления у шеи. Масштаб задаёт `HEAD_SCALE = .75`; исходный PNG не изменён, повторная генерация не нужна.

Проверено: `npm run build`; Playwright в Edge — четыре вида оружия, четыре направления, обычный и увеличенный масштаб, отдача, выбор Убийцы и переход в бой со стрельбой. Итоговый проход без ошибок JavaScript и загрузки ресурсов. Размеры PNG и прозрачность полей проверены. Скриншоты находятся в `output/playwright/assassin-angle-review.png`, `assassin-after.png`, `assassin-game.png`.
