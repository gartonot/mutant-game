# Ведьмак — портрет

Создан встроенным imagegen. Исходный PNG сохраняется без изменения в `src/assets/characters/witcher.png`.

Референс: `references/characters/witcher.png`. Бледное открытое лицо, тёмный облегающий головной убор, чёрная броня с зелёными линиями, руки у пояса, зелёное облако и рой насекомых. Это персонаж исходной игры «Мутант». Только портрет меню, игровой спрайт не создавался.

Закрытая карточка доступна для просмотра. По референсу показаны +10% скорости бега, восстановление 0,8 очка жизни в секунду, АК-47 (+120 патронов), лечение 3 очка в секунду при наведении мышкой и штраф −30% максимального здоровья. Цель наведения и остальные неизвестные условия лечения не выдуманы. Способность — «Рой жуков», без неподтверждённого описания действия. История ограничена известным фрагментом о лидере лагеря и решении зачистить нору жуков.

Всё это только отображение. Боевые эффекты, покупки, разблокировка и запуск боя за Ведьмака не добавлены.
