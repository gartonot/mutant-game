# Разрушитель: боевая модель v2

Рисованный стиль, принятый для Наёмника и Убийцы: мягкие тени, фактура ткани, кожи и металла, без толстой чёрной обводки. Разрушитель выделяется очень широкими плечами, массивными открытыми руками, зелёной майкой, лысой головой и патронташем.

Уточнение пользователя: камера **строго вертикально сверху**, без наклона и ракурса в три четверти. На голове видна макушка, лицо практически скрыто. Корпус и руки должны соответствовать той же проекции. Голова пропорциональна широким плечам, без увеличения как у первоначальных версий остальных героев.

Референсы: портрет `src/assets/characters/destroyer.png` и [игровой пример](references/destroyer-gameplay.png). Оружие остаётся отдельным слоем.

Создано встроенным imagegen. Исходный PNG: `src/assets/characters/destroyer-combat-v2.png`, 1774 × 887, с альфа-каналом. Корпус с руками расположен в x=0…1289, отдельная макушка — x=1290…1773. Исходное изображение сохранено без редактирования.

Рендер: `src/rendering/DestroyerArt.ts`, общий вызов `drawCharacter` для боя и предпросмотра. Порядок слоёв: тень, тело, выбранное оружие, макушка. Голова с `HEAD_SCALE = .75` привязана к шее, корпус шире остальных героев. Камера строго сверху; дополнительного поворота корпуса относительно оружия нет. Крепление и дульный срез берутся из `WeaponArt.ts`. Пока PNG загружается или при ошибке остаётся прежняя Canvas-модель; после загрузки предпросмотр перерисовывается.

Проверено: `npm run build`; Playwright в Edge — все четыре оружия, четыре направления, обычный и увеличенный масштаб, отдача, экран подготовки и бой со стрельбой. Итоговый проход без ошибок JavaScript и загрузки ресурсов. Проверены прозрачные поля PNG. Скриншоты: `output/playwright/destroyer-angle-review.png`, `destroyer-after.png`, `destroyer-game.png`.
