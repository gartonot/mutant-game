# Быстрая вкладка улучшений

31 октября 2026. Десять изображений отображались по 58–72 CSS-пикселя, но использовали отдельные PNG 256×256 общим весом 960 713 байт. Запросы начинались при открытии вкладки.

Теперь карточки и подсказки используют один WebP-атлас 960×384 с десятью ячейками 192×192. Вес — 89 896 байт (−90,6%). Атлас подготавливается вместе с остальными экранами в главном меню. Переход не ожидает загрузку. Встроенный атлас-превью весит 9336 байт и виден сразу даже при задержке внешнего изображения. Он добавляет около 10 КБ к сжатому начальному JS; исходники и полные старые экспорты сохранены.

Карточки и подсказки используют одинаковые координаты одного атласа, поэтому наведение не создаёт новых запросов. Логика очков, ограничений, сохранений и применения улучшений не менялась. Размеры иконок, рамки и размещение сохранены. Сравнительные кадры до/после осмотрены в игровом размере: значимого ухудшения не обнаружено. WebP quality 90 и уменьшение разрешения меняют пиксели; побитовое совпадение не заявляется.

## Проверка

346 тестов, TypeScript и production build проходят. Новая регрессия проверяет все 10 различных ячеек, встроенный слой, отсутствие Image-запросов до подготовки, один общий запрос, повтор после ошибки и кеширование успеха. Генератор `npm run assets:upgrades:check` проверяет воспроизводимость и SHA256 оригиналов.

Edge headless, 1440×900, отдельные холодные контексты. Ограниченная сеть CDP: 80 мс, 600 КиБ/с. Один прогон каждого сценария, не статистическая оценка и не точное соответствие пресету DevTools.

| --- | ---: | ---: |
| До, через 1 секунду после персонажей | 22 мс | 3287 мс |
| После, сразу после персонажей | 19 мс | 928 мс |
| После, через 1 секунду | 30 мс | 42 мс (уже загружены, включая проверку) |

Дополнительно проверены изменение здоровья и арсенала через «+», запись двух распределений в localStorage, сохранение значений после повторного открытия, подсказки без дополнительных запросов и немедленная доступность превью при полностью удерживаемом запросе атласа. Ошибок JS нет. Артефакты: `output/upgrades-qa/`.

Генерация: `npm run assets:upgrades`. Проверка: `npm run assets:upgrades:check`. Источники и настройки записаны в `src/assets/upgrades-runtime/manifest.json`.
