# Документация проекта

Актуализировано 1 ноября 2026 года.

## Текущее состояние

- Дизайн выбора персонажа, арсенала и дроверов бонусов, оружия и имплантов перенесён в игру. Утверждённые исходные макеты сохранены в [ui-concepts](ui-concepts/arsenal-design-notes.md).
- Улучшения работают: черновик, сохранение и отмена, применение к новому бою. Бюджеты оружия и имплантов пока раздельные; общий запас из концепта ещё не реализован.
- Проверка опубликованной версии после оптимизации загрузки завершена пользователем; BUG-006 закрыт. Остальные статусы см. в [списке багов](bugs.md).
- Обмен снаряжения, часть счётчиков и эффектов достижений и режим заданий остаются незавершёнными. Старые описания закрытых персонажей в отчётах о рисунках не определяют их текущую доступность.
- Генераторы ресурсов и промежуточные экспорты сохранены. Оригиналы изображений и утверждённые PNG/SVG не удалялись.

## Проверки

- `npm run lint` — ESLint для исходного TypeScript; сгенерированные файлы в `src/assets` и архив `output` исключены. Проверяются базовые ошибки, неиспользуемые переменные и повторные импорты; форматирование не навязывается.
- `npm test` — автоматические тесты.
- `npm run build` — проверка типов TypeScript и production-сборка Vite.

Все три проверки включены в workflow публикации GitHub Pages. ESLint не заменяет проверку типов или визуальную проверку игры.

## Как читать исторические отчёты

Документы с датами, отчёты о портретах и этапах оптимизации описывают состояние на момент соответствующей работы. Их результаты измерений и исходные референсы сохранены; прежние формулировки «пока не реализовано» не всегда описывают текущую игру. Текущую логику подготовки боя см. в [требованиях](pre-battle-requirements.md), архитектуру — в [gameplay-architecture.md](gameplay-architecture.md).

При очистке `output` удалены старые QA-сборки, скриншоты и экспериментальные изображения. Ссылки на них в исторических отчётах указывают на материалы прежних проверок, отсутствующие в текущем checkout. Скрипты, JSON результатов и оригиналы `output/imagegen/overhead-v4/originals` сохранены.

Страницы `/stress.html`, `/profile.html`, `/weapon-art.html` и `/character-art.html` больше не входят в проект. Прежние инструкции открыть эти страницы относятся к историческим стендам. Сохранённые QA-сценарии могут требовать восстановления baseline-сборки и настройки локального пути к Playwright.

JSON с измерениями и хешами в `docs/balance` фиксируют исходное состояние соответствующих запусков. Имена удалённых файлов в этих хешах сохранены как часть истории.
