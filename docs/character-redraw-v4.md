# Перерисовка шести боевых моделей — 27 октября 2026

Исправлены Полумутант, Голиаф, Фанатик, Ядерщик, Серебряный охотник и Ведьмак: вместо наклонного ракурса используются новые изображения с камерой вертикально сверху. У Ведьмака заново нарисованы плечи, локти и кисти. Образы, цвета костюмов и текущие игровые параметры сохранены.

## Файлы и подключение

Новые PNG находятся в `src/assets/characters/combat-v4/`: `half-mutant.png`, `goliath.png`, `fanatic.png`, `nuclear.png`, `silver-hunter.png`, `witcher.png`. Исходные PNG в v3 не заменялись.

`combat-v4/layout.ts` содержит новые области кадрирования, масштабы, повороты и центры ладоней. Остальные модели наследуют прежнюю калибровку. `AdditionalCharacterArt.ts` выбирает версию изображения из того же каталога замен, который использует `CharacterRig.ts`. Все оружия продолжают использовать общий расчёт крепления. Для Полумутанта и Голиафа добавлена маска макушки, чтобы приклад проходил за головой, а не поверх неё; маска следует повороту и отдаче тела.

## Генерация

Использован встроенный imagegen с прозрачным фоном. Точные исходные и уточняющие промпты, измерения и сведения о выбранных вариантах:

- `src/assets/characters/combat-v4/mutant-pair-notes.json`
- `src/assets/characters/combat-v4/hunters-generation.json`
- `src/assets/characters/combat-v4/energy-character-prompts.json`

Общее требование промптов: строго вертикальная ортографическая камера; видны макушка и верх плеч, без фронтального лица и груди; персонаж направлен вправо, естественные пустые кисти под отдельное оружие, прозрачность вокруг силуэта. Часть исходных поз потребовала небольшого поворота в плоскости изображения для горизонтального совмещения ладоней; это не наклон камеры.
