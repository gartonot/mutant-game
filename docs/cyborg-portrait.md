# Киборг — портрет

Портрет создан встроенным imagegen. Исходный PNG сохраняется без изменения в `src/assets/characters/cyborg.png`.

Референсы: `references/characters/cyborg.png` и `references/characters/cyborg-ingame.png`. Портрет сохраняет короткие тёмные волосы, металлические вставки на виске и челюсти, массивную броню, круглый бело-голубой элемент на груди, механическую руку слева для зрителя и обнажённую человеческую руку справа, плазмомёт с голубым стволом. Игровой спрайт не создавался.

Киборг добавлен в общий список закрытых персонажей для просмотра вместе с Охотником. По референсу показаны +70 очков жизни, +10% урона оружием, плазмомёт (+120 патронов) и название способности «Гравитационный удар». Действие способности не выдумано, история использует только известную часть. Открытие, покупка и боевые эффекты не реализованы. При просмотре «Играть» и «Снаряжение» недоступны; выбор доступного персонажа возвращает обычное поведение.
