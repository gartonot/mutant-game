# Маски огня и льда

Выполнено 28 октября 2026 года в `src/rendering/EnemyArt.ts`.

## Изменения

Раньше первый враг с каждым статусом создавал отдельный Canvas 1254×1254 и окрашивал весь исходник непосредственно из `drawEnemyArt`. Шесть комбинаций (три типа × огонь/лёд) создавались по мере первого использования.

Теперь `enemyArtReady()` сначала загружает изображения, затем готовит все шесть масок до начала боя. Между созданиями главный поток освобождается через таймер, чтобы окно подготовки оставалось отзывчивым. Чтение одного пикселя завершает отложенную растеризацию Canvas на этом этапе. Повторная подготовка использует кеш; одновременные вызовы разделяют одну задачу. Ошибка создания маски возвращает false для её типа и допускает повторную попытку.

Каждая маска содержит только используемую область исходника, существующий отступ 10 px и ещё 4 px вокруг него для фильтрации. Разрешение не уменьшено, цвет и прозрачность эффекта прежние. Исходные файлы не менялись. Во время отрисовки нет создания Canvas или окрашивания; берётся готовая маска.

| Маска каждого статуса | Раньше | Теперь |
| --- | --- | --- |
| Grunt | 1254×1254 | 738×695 |
| Tank | 1254×1254 | 823×782 |
| Boss | 1254×1254 | 836×786 |

Полный набор: **37 740 384 → 14 508 736 байт RGBA**, то есть **35,99 → 13,84 МиБ (−61,6%)**. Это расчёт объёма пикселей, а не замер всей памяти браузера/GPU. Раньше память выделялась только для уже встретившихся эффектов, теперь компактный набор выделяется заранее для каждого боя и повторно используется.

## Качество и проверки

108 браузерных отрисовок: три типа врагов, три состояния (обычный/огонь/лёд), масштаб Canvas 1/2/3 и четыре угла. Обычные изображения совпали точно. Для 72 окрашенных вариантов при сравнении с прежним полноразмерным способом максимальная разница составила 1/255 по цветовому каналу, всего 4627 изменённых каналов на 72 холста 600×600. Это не пиксельная идентичность; различия соответствуют округлению фильтрации Canvas после смены координат текстуры. Визуальное сравнение увеличенных изображений не выявило ухудшения.

Проверены совместная подготовка при параллельных вызовах, отсутствие пересоздания при повторе, отказ Canvas-контекста и успешная повторная попытка. 600 вызовов отрисовки после подготовки не создали ни одной маски. Сценарии старта игры, отмены, повторного боя, смены героя и сетевой ошибки также прошли.

Исследовательский локальный прогон до изменений показал около 101 мс на первые шесть эффектов вместе с принудительным чтением результата; после предварительной растеризации компактных масок — около 13 мс. Это единичные инструментированные замеры, не стабильный игровой benchmark и не обещание FPS. Первая передача текстур на GPU всё ещё может иметь стоимость; полный кадр с толпой требует отдельного нагрузочного теста.

Сборка прошла, модульные тесты — 192/192, включая четыре проверки кеша масок в `tests/enemy-art-cache.test.ts`. Браузерные сценарии и сравнение: `output/playwright/masks/` (`check.js`, `compare.js`, `lifecycle.js`, `comparison.png`).
